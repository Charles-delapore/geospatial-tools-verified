# 期刊级制图 8 条标准 · 出图检查清单

每出一幅投稿图，逐条打勾。客观项可由脚本检查，带 ★ 的项需人工目视判断。
设计宽度：单栏 17–18 cm（本管线原型宽度）；字体 pt 数只在设计印刷宽度下成立。

## S1 分面先行，一图一结论
- [ ] 每个分面只讲一个结论；分面标题为结论句或 (a)/(b) + 短标题
- [ ] 各分面共用同一分类、同一配色、同一图例（检查：共用同一个 norm/cmap 对象，只画一个 colorbar）
- [ ] 各分面共用同一比例尺逻辑（同一投影，或在图注中说明各分面比例尺关系）

## S2 配色讲语义
- [ ] 渲染器先于配色：定性→唯一值；有序数值→顺序色；有意义中点→发散色（中点已定义）；精确阈值→分级渲染（断点已记录）
- [ ] 类别数 ≤ 5–7
- [ ] 色盲模拟已跑（`prototype/colorblind_check.py`）：红绿色盲下各类别仍按明度有序可分
- [ ] 打印灰度下仍可区分（色盲模拟图的灰度倾向可作近似判断）★

## S3 底图退后
- [ ] 底图为浅色/去饱和（海洋、陆地浅填色，无饱和色块）
- [ ] 无道路、POI、注记等抢夺注意力的底图元素；如需底图注记，字号 ≤ 8 pt 且灰色

## S4 四件套齐全
- [ ] 图例（图例/色标，含单位与断点值）
- [ ] 比例尺（注明适用纬度，如“赤道处”；投影变形大时说明）
- [ ] 指北针（世界图经纬网已隐含方向时仍保留，或在图注中说明省略理由）
- [ ] 数据来源行（来源 + 年份 + 投影 + 软件，见 S8）
- [ ] 四件套无重叠、无裁切 ★（放大到 200% 检查边缘）

## S5 字体三级
- [ ] 标题 ≥ 12 pt；图例/轴注 9–10 pt；脚注/来源行 8 pt
- [ ] 按设计印刷宽度核对：pt = 像素 / (dpi/72)；图宽改变后重新核对
- [ ] 中文字体已注册且正常显示（matplotlib 默认 DejaVu 无 CJK，需显式注册 Noto Sans CJK SC）

## S6 统计图与地图分工
- [ ] 地图不承载数值比较（图上无成串数字标签）
- [ ] 数值比较由配对统计图或表格承担；如未配，在图注中说明数值见正文表 X

## S7 阈值标在图上，图注自足
- [ ] 阈值/分级断点标在图上（图例刻度或图面标注），不只在正文里
- [ ] 图注自足：不依赖正文即可读懂数据、方法与结论指向（每图附 `.caption.txt`）

## S8 复现信息进图注
- [ ] 数据来源与版本/获取日期
- [ ] 软件与版本号（绘图库、GMT、Python）
- [ ] 复现命令或脚本路径（`prototype/*.py` + 输入数据路径）
