## 4. 管线设计

两条主路线 + 一条备用路线。所有路线共用第 0–1 步与第 4–5 步。

```
[0 设计] → [1 数据准备] → [2 空间处理] → [3 制图] → [4 图面组装] → [5 质量检查]
```

### 第 0 步：设计宽度与版式决策（人工，约 10 分钟）

- 输入：期刊要求（单栏约 17–18 cm 或双栏约 24 cm）、图的数量与结论清单。
- 决策：设计宽度（**按印刷宽度出图**，字体 pt 才成立）、分面方案（每分面一个结论）、投影（世界图用 Robinson；区域图用等积或等距投影）。
- 输出：`figure-spec.md`（宽度、分面、投影、字体三级数值）。本原型：图 1 为 15 cm 单图，图 2 为 7.2 英寸（18.3 cm）双分面。

### 第 1 步：数据准备（自动化，脚本）

- 工具：GeoPandas（读 GeoJSON/Parquet/Shapefile）、pandas。
- 输入：公开数据（原型：Natural Earth 110m `ne_110m_admin_0_countries.geojson`，177 国）或复用 geovis 域已有数据。
- 处理：字段清洗、派生变量（如 `log10(POP_EST)`）、缺失值记录。
- 输出：清洗后数据 + 数据字典（字段、单位、年份、N）。人工点：确认变量语义与年份。

### 第 2 步：空间处理（半自动）

- 工具：GeoPandas + numpy（分类）、matplotlib colormap（取色）。
- 输入：第 1 步输出。
- 处理：① 分类：分位数/等距/自然断点，**类别 ≤ 5–7**；② 配色：按变量类型选渲染器（`gis-cartography-symbology` skill 的规则可作检查依据，未实测）；顺序色用 ColorBrewer 安全集（如 YlGnBu），发散色必须定义中点；③ 输出断点值表（供图例与图注共用）。
- 人工点：分类方法选择、断点是否合理；自动化：分类与取色计算。
- 坑：PyGMT `makecpt` 不认 ColorBrewer 名，需手写 CPT 文件（原型 `ylgnbu5.cpt` 由脚本按断点自动生成，见 §7）。

### 第 3 步：制图（三选一）

| 路线 | 适用 | 工具 | 输入 → 输出 |
|------|------|------|------------|
| A. PyGMT（推荐，静态印刷首选） | 单图、世界图、投稿主图 | PyGMT 0.19.0 / GMT 6.5.0 | 清洗数据 → 15 cm PNG（200 dpi）+ CPT 文件 |
| B. Cartopy + matplotlib（推荐，分面首选） | 多分面、地图+统计图并置 | Cartopy 0.26.0 / matplotlib 3.11.2 | 清洗数据 → 设计宽度 PNG（300 dpi） |
| C. QGIS MCP（备用，未实测） | 需打印布局、Atlas 批量出图 | nkarasiak qgis-mcp（125 工具） | QGIS 工程 → `create_layout` → `add_layout_map/legend/scalebar/picture/label` → `export_layout`（300 dpi） |
| 不推荐投稿 | 交互探索 | GeoLibre / lonboard / deck.gl / Bertin.js | 仅用于探索；默认缺四件套，Bertin.js 已停更 |

### 第 4 步：图面组装（半自动）

- 四件套：图例（原生 colorbar，断点作刻度）、比例尺与北箭头（**手绘**，见 §7 的教训：沿赤道画 5×1000 km 分段比例尺；北箭头用三角形 + "N"，放在经线近垂直的洋区）、来源行（见下）。
- 字体三级：标题 ≥ 12 pt、图例/轴注 9–10 pt、脚注 8 pt，**在设计宽度下核对**。
- 图注：每图一个 `.caption.txt`（模板：数据与 N、方法与断点、配色、软件与版本、复现命令）。图注是手写文本，无工具代劳。
- 页脚组装：GMT 的 `fig.text` 负偏移会落到保存页之外、正偏移会压到南极洲（均实测），故用 `assemble.py`（Pillow）在图下方加来源行条带；Cartopy 用 GridSpec 预留页脚行（`subplots_adjust` + `pad` 式布局会让色标标签撞上页脚，已实测并修正，见 §7）。

### 第 5 步：质量检查（半自动）

- 检查清单：`prototype/qa_checklist.md`（8 条标准逐项打勾，客观项脚本化、主观项人工目视）。
- 色盲模拟：`prototype/colorblind_check.py`（Machado et al. 2009 矩阵；红/绿色盲各一版，目视确认类别仍按明度有序可分）。
- 目视：放大到 200% 检查四件套重叠与边缘裁切；检查小字是否可读。
- 记录：检查结果写入图注或单独的检查记录，不口头通过。

### 残留瑕疵（已记录，未掩饰）

1. 图 1 的北箭头是地图坐标画的三角形，在 Robinson 投影下仍略带倾斜（经线收敛所致）；完全垂直的箭头应在图面/纸面坐标下画（路线图第 2 项）。
2. 图 2 面板间上方留白较大（Robinson 椭圆纵横比所致），属版式问题，不违反任何标准。
3. 图 1、图 2 的色盲模拟中，中间两类（第 3、4 级）在红绿色盲下最接近，仅靠明度区分；类别再多一级就会糊掉——5 类是上限。

## 7. 验证记录（实测中发现的坑）

以下均为本任务实测，非转述：

1. **PyGMT `makecpt` 不认 "YlGnBu"**：`cmap="YlGnBu"` 与小写 `"ylgnbu"` 均报 `GMT_Read_Data: File not found`；十六进制颜色列表亦被拒（`-C` 重复）。geovis 脚本用过的 `"viridis"` 可用。解决：按断点手写 CPT 文件（原型脚本自动生成）。
2. **PyGMT 新 API 比例尺画斜线**：`Figure.scalebar(length="1000k", position="BL", fancy=True)` 在全球 Robinson 图上画出一条斜穿全图的直线；旧 API `basemap(map_scale=...)` 的比例尺在帧边缘裁切、只剩 "1000" 标签。解决：地图坐标手绘 5 段比例尺。
3. **PyGMT 指北针裁切**：旧 API `rose="jTR+w1.2c+f1+o0.5c/0.5c"` 的箭头贴在帧右上角边缘、半个在外。解决：手绘三角形 + "N"。
4. **PyGMT 页脚放不下**：`fig.text(position="BC", offset="0c/-0.6c")` 的文字落在保存页之外（不可见）；正偏移则压到南极洲上。解决：Pillow 在图下方加条带（`assemble.py`）。
5. **PyGMT `plot(data=..., x="lon", y="lat")` 被拒**：本机 pygmt 0.19.0 报 `Mutually exclusive parameters: 'data', 'x/y/z'`；改传 `x/y` 数组后通过。
6. **Cartopy 色标标签撞页脚**：`subplots_adjust` + `pad` 式布局下，色标标签与 `fig.text` 页脚重叠；改 GridSpec 三行布局（面板 / 色标 / 页脚各占一行）后解决。
7. **字体 pt 与图宽**：初版图 2 为 12 英寸宽、8 pt 页脚，缩到单栏印刷时有效字号约 4.5 pt；改为 7.2 英寸设计宽度后，pt 数在印刷宽度下成立。
8. **matplotlib 默认字体无 CJK**：需显式注册 Noto Sans CJK SC（geovis 报告已验证的坑，本任务沿用）。
